# Kaique Oli — Personal Website

A premium, cinematic personal website designed with a focus on visual storytelling, texture, and professional presence. Inspired by the visual identity of `links.kaiqueoli.com`.

## 🌌 Visual Philosophy
The project follows a **Deep Dark / Glassmorphism** aesthetic:
- **Cinematic Hero**: Full-screen video background with minimalist typography.
- **Structured Content**: 2x2 photo grids and full-screen featured sections.
- **Premium UX**: Smooth reveal animations, animated radial glows, and high-quality interactive feedback.
- **Silent Luxury**: A focused, controlled interface that avoids clutter and prioritizes content.

## 🛠 Technical Stack
- **Foundation**: Semantic HTML5, Vanilla JavaScript (ES6+).
- **Styling**: Modern CSS3 using Custom Properties (Variables), Flexbox, Grid, and Backdrop Filters.
- **Performance**: Zero external dependencies, optimized for fast loading and SEO.
- **Aesthetics**: Custom-designed glassmorphism system and dynamic background animations.

## 📂 Project Structure
```text
├── about/              # Professional profile and contact
├── archive/            # Filterable grid of articles and projects
├── article/            # Detailed essay and blog post layouts
├── assets/
│   ├── css/            # Multi-layered design system (styles.css)
│   ├── js/             # Interactive logic (toc, filters, nav)
│   └── video/          # Cinematic background assets
├── 404.html            # Custom error page
└── index.html          # Main cinematic landing page
```

## 🚀 Getting Started
To run the project locally, any static file server will work:

**Node.js (recommended):**
```bash
npx serve .
```

**Python:**
```bash
python -m http.server 8080
```
